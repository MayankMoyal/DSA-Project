## 1. Definitions and claim

Assume a finite binary search tree (BST) storing distinct keys.

For a node v:

- k(v) denotes its key.
- Lᵥ and Rᵥ denote its left and right subtrees.
- K(U) denotes the set of keys in a subtree U.
- An empty subtree has no keys.

The BST invariant consists of two independent requirements at every node v:

- Every key a in K(Lᵥ) satisfies a < k(v).
- Every key b in K(Rᵥ) satisfies k(v) < b.

These requirements apply to all descendants, not only immediate children. An empty subtree imposes no restriction on its side.

**Claim:** Hibbard deletion preserves BST order. If the requested key x exists, it removes exactly x; otherwise, it leaves the tree unchanged. This holds for both successor and predecessor replacement.

## 2. Ancestor bounds

Every ancestor of a node z imposes a bound on all keys in the subtree rooted at z:

- If z lies in an ancestor's left subtree, every key below z must be smaller than that ancestor's key.
- If z lies in an ancestor's right subtree, every key below z must be greater than that ancestor's key.

Therefore, replacing the subtree rooted at z by a valid BST containing only keys from that original subtree preserves all ancestor constraints.

At the root, there are no ancestor constraints.

It suffices to show that the modified subtree is a valid BST containing exactly its original keys except x.

## 3. Case 1: The node is a leaf

If x is absent, deletion changes nothing, so BST order is preserved.

Otherwise, let z be the node containing x. The incoming link to z means its parent's child pointer, or the tree's root pointer when z is the root.

Suppose z is a leaf. Replace its incoming link by null and remove z.

All surviving keys and all links between surviving nodes are unchanged. Therefore, every remaining ordering inequality still holds, and exactly x is removed.

If z was the root, the resulting empty tree is a valid BST.

## 4. Case 2: The node has exactly one child

Let C be the nonempty child subtree of z. Replace the incoming link to z by the root of C, then remove z.

The subtree C remains a valid BST because none of its internal links changes. Every key in C already satisfied all bounds imposed by ancestors of z. These bounds remain satisfied after reconnection.

Thus, the entire tree remains a BST, and exactly x is removed.

This argument applies whether C is the left or right child subtree. If z was the root, the root of C becomes the new root.

## 5. Case 3: The node has two children

Let L and R be the original left and right subtrees of z, whose original key is x. Both subtrees are nonempty.

The original BST invariant gives:

- a < x for every a in K(L).
- x < b for every b in K(R).

Hibbard deletion copies either the successor or predecessor key into z and removes that key's original node.

### 5.1 Successor replacement

Let y be the leftmost node of R, and let its key be s. Thus:

**s = min K(R).**

#### The successor has at most one child

The node y cannot have a left child. Such a child would have a key smaller than s within R, contradicting the minimality of s.

Therefore, y has at most a right child subtree C.

#### Reconnecting its child preserves order

Copy s into z. Replace the incoming link to y by C and remove y.

There are two possibilities:

- **y is deeper in R:** Then y is the left child of its parent q. Every key c in C originally satisfies s < c < k(q). Therefore, C can replace y as q's left subtree. All other ancestor bounds within R remain satisfied because C already lay below y.
- **y is the immediate right child of z:** Then C becomes z's right subtree. Every key in C is greater than the new key s.

If C is empty, the replacement link is null. Otherwise, its internal links remain unchanged.

Consequently, the remaining right subtree R′ is a valid BST containing all original keys of R except s.

#### The new key preserves order at z

For every key a in L:

**a < x < s.**

For every key b remaining in R′:

**s < b.**

The second inequality follows because s was the smallest key in R and all keys are distinct.

Thus, every left-subtree key is smaller than s, and every right-subtree key is greater than s. Both child subtrees are valid BSTs, so the modified subtree is a valid BST.

#### Exactly x is removed

The original subtree contains:

**K(L) ∪ {x} ∪ K(R).**

The modified subtree contains:

**K(L) ∪ {s} ∪ (K(R) ∖ {s}) = K(L) ∪ K(R).**

Therefore, exactly x is removed. The successor key s remains once, at z.

### 5.2 Predecessor replacement

Let y be the rightmost node of L, and let its key be p. Thus:

**p = max K(L).**

#### The predecessor has at most one child

The node y cannot have a right child. Such a child would have a key greater than p within L, contradicting the maximality of p.

Therefore, y has at most a left child subtree C.

#### Reconnecting its child preserves order

Copy p into z. Replace the incoming link to y by C and remove y.

There are two possibilities:

- **y is deeper in L:** Then y is the right child of its parent q. Every key c in C originally satisfies k(q) < c < p. Therefore, C can replace y as q's right subtree. All other ancestor bounds within L remain satisfied because C already lay below y.
- **y is the immediate left child of z:** Then C becomes z's left subtree. Every key in C is smaller than the new key p.

If C is empty, the replacement link is null. Otherwise, its internal links remain unchanged.

Consequently, the remaining left subtree L′ is a valid BST containing all original keys of L except p.

#### The new key preserves order at z

For every key a remaining in L′:

**a < p.**

For every key b in R:

**p < x < b.**

The first inequality follows because p was the largest key in L and all keys are distinct.

Thus, every left-subtree key is smaller than p, and every right-subtree key is greater than p. Both child subtrees are valid BSTs, so the modified subtree is a valid BST.

#### Exactly x is removed

The modified subtree contains:

**(K(L) ∖ {p}) ∪ {p} ∪ K(R) = K(L) ∪ K(R).**

This is precisely the original subtree's key set with x removed. The predecessor key p remains once, at z.

## 6. Conclusion

In all three cases, the modified subtree is a valid BST containing exactly its original keys except x. Its surviving keys satisfy every ancestor bound, and all other subtrees remain unchanged.

Therefore, Hibbard deletion preserves BST order throughout the entire tree, including when the deleted node is the root.

Both two-child replacement choices are individually correct. Hence the proof applies to always-successor deletion and to every sequence of randomized predecessor/successor choices.

The invariant holds after the complete deletion operation. During two-child deletion, copying the replacement key temporarily duplicates it until its original node is removed.

**This completes the proof.**
