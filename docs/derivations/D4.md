# D4 · Expected average depth after random BST insertion

Author: Bahiram Sai Chhagan · mc250041007 · Oracle owner · CS 253 / MA 253 · Project 3

## Model and quantity

Insert a uniformly random permutation of n distinct keys into an initially empty ordinary BST. Count depth in edges, with the root at depth zero. Let Pₙ be the expected sum of all node depths (internal path length). Set P₀ = P₁ = 0. For n ≥ 1 the expected average node depth is Pₙ/n, since n is fixed.

## Condition on the first key

The first key becomes the root. Its rank is uniform, so the left subtree has k keys with probability 1/n for each k from 0 to n−1. The right subtree has n−1−k keys. Conditional on k, the relative insertion order on each side is uniform. Attaching both subtrees below the root adds one edge to the depth of each of their n−1 keys. By linearity of expectation and symmetry of the sum,

    Pₙ = (1/n) Σ[k=0..n−1] (Pₖ + Pₙ₋₁₋ₖ + n−1)
       = n−1 + (2/n) Σ[k=0..n−1] Pₖ.

## Remove the sum and telescope

Multiply by n. Write the same equation at n−1 and subtract it, for n ≥ 2:

    nPₙ − (n−1)Pₙ₋₁ = 2(n−1) + 2Pₙ₋₁,
    nPₙ = (n+1)Pₙ₋₁ + 2(n−1).

With Qₙ = Pₙ/(n+1), division by n(n+1) gives

    Qₙ − Qₙ₋₁ = 2(n−1)/[n(n+1)] = −2/n + 4/(n+1).

The step also gives zero for n=1 with Q₀=Q₁=0. Sum from 1 through n. Write Hₙ = Σ[j=1..n] 1/j. Then Qₙ = −2Hₙ + 4(Hₙ₊₁−1) = 2Hₙ − 4n/(n+1). Hence

    Pₙ = 2(n+1)Hₙ − 4n,
    Pₙ/n = 2(1 + 1/n)Hₙ − 4 = 2 ln n + O(1).

The last step follows from ln(n+1) ≤ Hₙ ≤ 1+ln n. The logarithm is natural. A successful search counts one more visited node than its depth in edges.

## Check and interpretation

At n=3, two of the six orders put the middle key first and have total depth 2. The other four produce chains of total depth 3. The average over all nodes and orders is (2×2 + 4×3)/(6×3) = 8/9. The exact formula agrees. The [C++ check](../../oracle/test_d4.cpp) enumerates all permutations up to n=8 and compares Structure A's internal path length with the formula.

The theorem describes initialization by random insertion. It does not establish a depth bound for ordinary deletion–insertion churn, the restricted exact-fit model, or either rebuilt scapegoat shape. The sorted array certifies contents, while the trees supply shape-specific depths.
