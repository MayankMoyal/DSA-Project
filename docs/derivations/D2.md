# D2: Existence of a Scapegoat

## Search Trees under Long-Running Churn

**Author:** Krish Zinzuvadiya  
**Role:** Structure B Owner

## Abstract

A scapegoat tree answers an insertion that lands too deep by locating an ancestor that is not weight-balanced and rebuilding its subtree. This note proves that such an ancestor always exists whenever the depth test is triggered, so the rebuilding step is well defined. The note also records the consequences of the result for the implementation.

## 1. Definitions

Fix a constant \(\alpha\) with

\[
\frac{1}{2}<\alpha<1.
\]

For \(\alpha=\frac{1}{2}\), perfect balance would be required after every insertion, which is not achievable, and as \(\alpha\to1\) the balance condition becomes vacuous.

Let \(T\) be a binary search tree. For a node \(v\), \(\operatorname{size}(v)\) denotes the number of nodes in the subtree rooted at \(v\), including \(v\), with

\[
\operatorname{size}(\text{null})=0.
\]

The *depth* of a node is the number of edges on the path from the root to it, so the root has depth \(0\).

**Definition 1 (\(\alpha\)-weight-balanced node).** A node \(v\) is *\(\alpha\)-weight-balanced* if

\[
\operatorname{size}(v.\mathrm{left})\leq
\alpha\,\operatorname{size}(v)
\]

and

\[
\operatorname{size}(v.\mathrm{right})\leq
\alpha\,\operatorname{size}(v).
\]

A node that does not satisfy both inequalities is *\(\alpha\)-weight-unbalanced*. Every leaf is \(\alpha\)-weight-balanced, since both of its children have size \(0\).

**Definition 2 (Scapegoat).** Let \(x\) be a node that has just been inserted, and let

\[
v_0,v_1,\dots,v_d=x
\]

be the path from the root \(v_0\) to it, so that \(d\) is the depth of \(x\). A *scapegoat* for \(x\) is a node \(v_i\) with \(0\leq i\leq d-1\) that is \(\alpha\)-weight-unbalanced.

The scapegoat insertion rule is as follows. Let

\[
n=\operatorname{size}(v_0)
\]

be the number of nodes in the tree after the insertion. If

\[
d>\log_{1/\alpha}n,
\]

a scapegoat is located and its subtree is rebuilt into a perfectly balanced tree. The rule is well defined only if a scapegoat is guaranteed to exist whenever \(d>\log_{1/\alpha}n\).

## 2. Theorems

**Theorem 1.** *Let \(x\) be a newly inserted node at depth \(d\) in a binary search tree with \(n\) nodes, counting \(x\). If*

\[
d>\log_{1/\alpha}n,
\]

*then at least one proper ancestor of \(x\) is not \(\alpha\)-weight-balanced.*

## 3. Proof

The proof establishes the contrapositive: if every proper ancestor of \(x\) is \(\alpha\)-weight-balanced, then

\[
d\leq\log_{1/\alpha}n.
\]

Assume that \(v_0,\dots,v_{d-1}\) are all \(\alpha\)-weight-balanced.

**Lemma 1.** *For every \(i\) with \(0\leq i\leq d-1\),*

\[
\operatorname{size}(v_{i+1})
\leq
\alpha\,\operatorname{size}(v_i).
\]

**Proof.** The node \(v_{i+1}\) is the left or the right child of \(v_i\). Since \(v_i\) is \(\alpha\)-weight-balanced, each of its children has size at most \(\alpha\,\operatorname{size}(v_i)\). \(\square\)

**Lemma 2.** *For every \(j\) with \(0\leq j\leq d\),*

\[
\operatorname{size}(v_j)
\leq
\alpha^j\,\operatorname{size}(v_0).
\]

**Proof.** By induction on \(j\). For \(j=0\), the claim is an equality. If it holds for some \(j<d\), then Lemma 1 and \(\alpha>0\) give

\[
\begin{aligned}
\operatorname{size}(v_{j+1})
&\leq \alpha\,\operatorname{size}(v_j)\\
&\leq \alpha\cdot\alpha^j\operatorname{size}(v_0)\\
&= \alpha^{j+1}\operatorname{size}(v_0).
\end{aligned}
\]

\(\square\)

Apply Lemma 2 with \(j=d\). The node \(x=v_d\) is a leaf, so

\[
\operatorname{size}(v_d)=1,
\]

and

\[
\operatorname{size}(v_0)=n.
\]

Therefore,

\[
1\leq\alpha^d n,
\qquad\text{that is,}\qquad
(1/\alpha)^d\leq n.
\]

Since \(1/\alpha>1\), the function \(t\mapsto\log_{1/\alpha}t\) is increasing, and taking logarithms gives

\[
d\leq\log_{1/\alpha}n.
\]

This is the negation of \(d>\log_{1/\alpha}n\).

Consequently, if \(d>\log_{1/\alpha}n\), the assumption that all proper ancestors of \(x\) are \(\alpha\)-weight-balanced is false, and some \(v_i\) with \(0\leq i\leq d-1\) is \(\alpha\)-weight-unbalanced. \(\blacksquare\)

## 4. Consequences for the Implementation

### 4.1. Location of the scapegoat

The scapegoat lies among \(v_0,\dots,v_{d-1}\); the inserted leaf is always balanced and need not be tested. The proof shows more precisely that some index \(i\) satisfies

\[
\operatorname{size}(v_{i+1})
>
\alpha\,\operatorname{size}(v_i),
\]

and the corresponding \(v_i\) is a scapegoat.

The standard procedure ascends from \(x\), maintaining the size of the child on the path, computing the size of each ancestor, and stops at the lowest ancestor for which this inequality holds. By Theorem 1, the ascent terminates at or below the root. The implementation asserts this, and the differential test against the oracle exercises the assertion on every insertion that triggers the depth test.

### 4.2. Use of an upper bound on \(n\)

When deletions are processed lazily, the depth test may be evaluated against \(q\geq n\), for example the maximum tree size since the last full rebuild. The theorem remains applicable:

\[
d>\log_{1/\alpha}q
\geq
\log_{1/\alpha}n.
\]

A threshold computed from a value \(q<n\) would not satisfy the hypothesis of the theorem. This requirement is recorded as a structural invariant in `INTERFACE.md`.

### 4.3. Integer arithmetic

Because \(d\) is an integer, the condition

\[
d>\log_{1/\alpha}n
\]

is equivalent to

\[
d>\left\lfloor\log_{1/\alpha}n\right\rfloor.
\]

The comparison is carried out with integer-safe arithmetic (a precomputed threshold table or a comparison of \(\alpha^d n\) with \(1\)) so that floating-point error at the boundary cannot change the outcome.

### 4.4. Scope of the result

Theorem 1 establishes existence only. The cost of locating the scapegoat and rebuilding its subtree is treated in the amortised analysis (derivation D6), and the height of the tree after a rebuild is a separate property of the scheme of Galperin and Rivest that this note does not claim.
