Each panel shows the always-successor Hibbard BST after the same number of fixed-population churn pairs. The initial keys and seed are shared. Only the workload changes. Advance the steps to see how each trace reshapes the tree.

Initial tree · pair 0 of 32
What the four workloads do. Random deletes a uniformly chosen live key and inserts a random absent key. Exact also deletes uniformly, then reinserts that same key. Shallow exact and shallow fresh use the first two-child node found breadth-first through depth 3 (or a uniform deletion fallback); they reinsert the removed key or a random absent key, respectively.

Each frame is produced from the project’s C++ adversary generators and the actual Hibbard successor tree. n = 15, seed = 42, 32 pairs. Small traces illustrate the workload rules; they do not establish asymptotic behavior or predict the large experiments.
