# Build and analysis tools

Original papers by Eppinger, Culberson-Munro, Galperin-Rivest and Stout-Warren were consulted. g++ compiled the programs; C++ runs produced the raw measurements. Python orchestrated experiments and computed means/sample SD; Matplotlib generated figures; ReportLab generated PDFs; PyMuPDF rendered and checked the PDFs. Git records the three delivery commits.

Verification corrected target selection to enforce the documented depth limit. The separate reference version also changes teammates' draft modules, including perfect-leaves rebuilding.
